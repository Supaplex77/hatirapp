Kebijakan Privasi

Terakhir diperbarui: 28 September 2026

Kami di aplikasi Hatır ("Aplikasi") menghormati privasi Anda. Kebijakan Privasi ini menjelaskan dengan jelas dan transparan bagaimana data Anda ditangani saat Anda menggunakan Aplikasi kami.

Penting: Data yang Anda masukkan di Aplikasi — seperti nama kontak, nomor telepon, tanggal ulang tahun, atau konten pengingat — tidak dikirim atau dikumpulkan oleh server kami. Informasi ini disimpan hanya secara lokal di perangkat Anda.

1. Data yang Disimpan Secara Lokal

Data berikut yang Anda berikan untuk fitur inti Aplikasi hanya disimpan di perangkat Anda:

  • Nama, nomor telepon, dan tanggal ulang tahun orang yang ingin Anda jaga kontaknya
  • Pengingat yang Anda buat dan preferensi Anda
  • Pengaturan notifikasi dan preferensi frekuensi

Data ini tidak pernah ditransfer ke server mana pun; tetap sepenuhnya di perangkat Anda. Tidak dapat diakses oleh aplikasi lain atau pihak ketiga.

2. Data Teknis yang Kami Kumpulkan

Aplikasi tidak memerlukan akun dan tidak pernah mengirim konten yang Anda masukkan ke mana pun. Agar Aplikasi tetap stabil, hanya informasi teknis berikut yang diproses:

  • Laporan crash: Detail teknis untuk memperbaiki crash (mis. stack trace, model perangkat, versi iOS, versi aplikasi). Konten yang Anda masukkan tidak pernah disertakan.
  • Pengaturan aplikasi: Saat dimulai, Aplikasi membaca pengaturan seperti versi minimum yang didukung dan status pemeliharaan dari server. Hanya detail teknis seperti versi aplikasi yang dikirim dengan permintaan ini.
  • Pengenal instalasi anonim: Pengenal acak yang khusus untuk instalasi Aplikasi ini, diperlukan untuk layanan di atas. Pengenal ini tidak mengidentifikasi Anda secara pribadi.

Informasi ini diproses melalui Firebase Crashlytics dan Firebase Remote Config. Tidak ada statistik penggunaan, data analitik, atau data iklan yang dikumpulkan.

3. Cara Kami Menggunakan Data Anda

Kami menggunakan informasi teknis ini hanya untuk:

  • Mendeteksi dan memperbaiki kesalahan serta menjaga Aplikasi tetap stabil
  • Menjaga pengaturan Aplikasi tetap terkini (mis. memberi tahu Anda saat pembaruan diperlukan)

Pengingat dan notifikasi dibuat dan dijadwalkan sepenuhnya di perangkat Anda.

4. Penyimpanan dan Keamanan Data

Data pribadi yang Anda masukkan disimpan hanya di perangkat Anda. Anda dapat menghapus orang satu per satu di dalam Aplikasi, atau menghapus semua data Anda dengan menghapus Aplikasi dari perangkat Anda. Laporan crash dikirim melalui koneksi terenkripsi dan disimpan di server Google yang aman.

5. Layanan Pihak Ketiga, Iklan, dan Pelacakan

Aplikasi hanya menggunakan Firebase Crashlytics untuk laporan crash dan Firebase Remote Config untuk pengaturan aplikasi (keduanya dari Google). Penyedia ini menerapkan langkah keamanan standar industri dan tunduk pada kebijakan privasi mereka sendiri.

Aplikasi tidak menampilkan iklan dan tidak melacak Anda di aplikasi atau situs web milik perusahaan lain.

6. Privasi Anak

Aplikasi kami ditujukan untuk pengguna berusia 4 tahun ke atas. Kami tidak dengan sengaja mengumpulkan data dari anak di bawah 4 tahun. Orang tua dapat mengawasi penggunaan Aplikasi oleh anak-anak mereka.

7. Perubahan

Kami mungkin memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan signifikan akan dikomunikasikan melalui Aplikasi.
